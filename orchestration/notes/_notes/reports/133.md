## Spec ambiguities resolved

- Dismissal "from root search" with no new UI element: an Actions panel entry "Dismiss Notice" on the notice row; the About page dismisses by opening the folder.
- The notice is not persisted: it exists only for the start that found a stale marker (so a clean quit plus a start removes it, per spec).
- An unreadable marker is removed without reporting a crash; a running process whose start time the system does not give counts as the marker's (never a false "crashed").
- SIGTERM/SIGINT/SIGHUP marker removal is installed on macOS as well as Linux (a `kill` is not a crash); macOS session end still goes through GPUI's termination hook.
- Status line at start says "Pane quit unexpectedly last time" (as a Result, only if nothing else was there), mirroring the update row's status word.
- Rate-limit site = the format string; for adapter messages, the text before the first `:`. Panics share the site "panic".
- Copy diagnostics keeps full paths (the user's explicit copy, as the data folder already was); only the log is redacted.
- The redaction rule follows the spec literally (substring, ≥ 3 chars), so a user named e.g. "pane" would also redact "Pane" in messages; word-boundary matching was not added.

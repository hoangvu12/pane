# Idle cost (#188): the timers sleep, icons are not re-extracted, history is shared and batched

Four tickets, one commit per ticket, on top of the quick fixes and file-index targets that just landed:

- **#191 — icon refresh.** An application's icon is extracted again only when its source changed (the shortcut's target or icon location, the manifest or logo files, the bundle's `Info.plist`, the desktop entry's icon) or its cached picture is a week old; an on-demand row still draws from the cache at once, and a picture past the age is refreshed in the background. An old cache index is read without loss, with its pictures counted as old.
- **#189 — measurement.** `scripts/proc_tree.py` samples every thread and `summary.json` gains wake-ups per thread name in `hidden-idle` and `idle-core`; `measure-linux.sh` gains the hidden phases (they run in the release matrix's `Smoke (ubuntu-24.04)` after the smoke), and a new `scripts/measure-windows.ps1` runs the same workload against a scratch data folder on Windows, writing the same summary shape.
- **#190 — sleeping timers.** Each runtime thread counts requests in flight from the moment one is sent until it has been served. While none is, the epoch ticker and the watchdog wait on a condvar without a timeout (a call starting, a poll starting and the thread's end wake them; each check-and-wait is under the same lock as the count). While a call is in flight both behave exactly as before. A race test starts computing calls as the ticker goes to sleep.
- **#192 — shared, batched clipboard history.** The view shares one `Arc<[ClipboardRecord]>` with the Actions panel instead of cloning the history per frame, and its writes are batched (500 ms, a clean quit or session end flushes; command changes still write before returning). A copy made less than the delay before a crash can be lost — documented. Items stay protected (#130) and are encrypted once.

#191 [OPEN] Extract an application's icon again only when its source changed or the picture is a week old
## Parent

https://github.com/hoangvu12/pane/issues/188

## What to build

Section 3 of the parent, "Application icons": an application's icon is extracted again only when the file it is read from changed, or when its cached picture is older than 7 days. It is no longer extracted for every application after every start. Size S.

Today (104a5dac), `crates/pane-core/src/applications/icons.rs` (module doc ~25-40, the worker's `run` ~962-981) re-extracts every listed application's icon once after each start. Only on-demand (urgent) jobs skip an unchanged fingerprint. [Applications](https://github.com/hoangvu12/pane/blob/main/docs/applications.md) documents this (~343-360). Per ~510, a shortcut's fingerprint follows the shortcut itself. That is likely why every start re-extracts: a shortcut whose target was updated keeps its own size and time.

What to build:

- The fingerprint covers the file the picture is read from:
  - a shortcut's icon location, or else its target;
  - a packaged app's logo asset;
  - an app bundle's icon file;
  - a desktop entry's resolved themed icon file.
  
  It keeps covering the source as today.
- Background jobs skip an application whose fingerprint is unchanged and whose cached picture is younger than the refresh age (7 days, proposed). Missing, changed and old pictures are extracted, a few at a time at low priority, on-demand ones first, as today.
- The cache's index records when each picture was extracted. An index from before this change is read with every picture treated as old, so nothing is lost and no rebuild is forced.

## Acceptance criteria

- [ ] Core tests with the recording extractor (prior art: the applications and icons tests):
  - a restart over the same cache extracts nothing for unchanged applications;
  - a shortcut whose target changed is extracted again;
  - a picture past the refresh age is extracted again in the background;
  - an on-demand row still draws from the cache at once.
- [ ] Windows: a shortcut's fingerprint includes its icon location or target. The packaged-app, app-bundle and desktop-entry adapters compile, and are tested where CI runs them.
- [ ] An old cache index is read without loss.
- [ ] `docs/applications.md` describes the new refresh rule.
- [ ] CI: the branch tier is green, and a `ci-fast` verify run is green. No release matrix.

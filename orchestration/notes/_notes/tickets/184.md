#184 [OPEN] Leave network and removable roots out on Windows and macOS, and count churn only for paths the index admits
## Parent

https://github.com/hoangvu12/pane/issues/126

## What to build

Two places where the file index does not do what `docs/files.md` and the parent say. Size S.

- **Other volumes on Windows and macOS.** `docs/files.md` (~157-166) and the parent's "Scope and rules" leave network and removable volumes out by default, behind the `includeOtherVolumes` switch. The walker only checks this on Linux (`statfs`, `crates/pane-core/src/file_index/walker.rs` ~562-600); elsewhere a stub answers "not another volume". Its comment explains that junctions are never followed on Windows. But a root that is itself on a network share or a removable drive (an added root, or a home folder redirected to a share) is walked and watched as if it were local.
  - On Windows, ask `GetDriveTypeW` (resolving a mapped drive to its volume) for each root, and for any folder the walker would enter on another volume.
  - On macOS, use `statfs` `f_flags` (`MNT_LOCAL`, and removable media).
  - Such a volume follows the documented rules: left out unless the switch is on, and when on, a network share is never watched live, only reconciled.
- **Churn quarantine counts paths the index never admits.** `count_churn` (`indexer.rs` ~1465-1519) skips only roots and the user's excluded folders. Paths that are ignored, hidden, under the default exclusions (`node_modules`, caches, temporary folders) or always excluded are counted too. A busy `.git` or `node_modules` can therefore be quarantined (`indexer.rs` ~1524). That saves a user rule in `file-search.json` and shows a misleading row on the File Search page. Count only paths the scope admits, sharing the batch's admission memo.

## Acceptance criteria

- [ ] Unit tests through a volume-kind seam: a root reported as a network or removable volume is left out by default and included when the switch is on, for Windows and macOS (with a fake answer; the real calls are compiled on the `ci-fast` verify run's macOS leg).
- [ ] A test with a fixture home: a burst of changes inside `node_modules`, an ignored folder and a hidden folder never quarantines anything. The same burst in an indexed folder still does, with the existing thresholds.
- [ ] `docs/files.md` states the volume check per system as it now is.
- [ ] Release-validation evidence, not a merge gate: an added root on a real network share or USB drive on Windows. Ask the user before mapping or plugging anything.
- [ ] CI: the branch tier is green, and a `ci-fast` verify run is green. No release matrix.

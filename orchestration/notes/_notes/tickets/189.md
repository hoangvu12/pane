#189 [OPEN] Measure Pane's cost while hidden and count wake-ups per thread, on Linux and Windows
## Parent

https://github.com/hoangvu12/pane/issues/188

## What to build

Section 1 of the parent, "Measurement": Pane's cost while hidden is measured, wake-ups are counted per thread, and the numbers on `main` today are recorded as the baseline. Size S.

- `scripts/measure-linux.sh` / `scripts/proc_tree.py` gain:
  - a `hidden-idle` phase (Pane hidden after one show, defaults only, 60 s), recording whole-tree CPU share;
  - per-thread voluntary context switches over the phase, read from `/proc/<pid>/task/*/status` and named by thread name.
  
  `idle-core` gains the same counts. `summary.json` carries them, and `scripts/resource-targets.json` gains the phase with null ceilings.
- A Windows script beside `scripts/smoke-windows.ps1` records the same for a scratch Pane on a scratch data folder, with `PANE_DATA_DIR` and `LOCALAPPDATA` pointed at a temporary folder: process CPU time and per-thread context switches over a hidden 60 s. It must never capture the screen, never focus Pane over the user's windows except for the one show, and never touch the user's own Pane data.
- Record the baseline in [resource measurements](https://github.com/hoangvu12/pane/blob/main/docs/research/resource-measurements.md):
  - from a Linux run (CI or on demand);
  - from the Windows script on the user's machine, **only when the user says the machine is free; it is also used for games.**

## Acceptance criteria

- [ ] `summary.json` has `hidden-idle` with CPU share and wake-ups per thread name, and `idle-core` has the wake-ups too.
- [ ] `resource-targets.json` lists the new phase with null ceilings. `proc_tree.py check` still reports pending and passes.
- [ ] The Windows script runs against a scratch data folder and writes the same summary shape.
- [ ] The baseline is recorded (Linux, and Windows with the user's consent), showing the `pane-runtime-epoch` and `pane-runtime-watchdog` wake-ups.
- [ ] `docs/research/resource-measurements.md` describes the phase and the Windows script.
- [ ] CI: the branch tier is green. If a CI job runs the measurement, its run is linked. No release matrix.

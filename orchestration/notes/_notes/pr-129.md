# Quick fixes (#129): five independent fixes, one commit per ticket

- **#182 — the hotkeys document.** `docs/hotkeys.md` and the decision index describe the Open Pane hotkey (its defaults, its Settings location, its refusal wording, its Wayland limit) and Settings' Shortcuts page as they are. Documentation only.
- **#130 — protected credentials and clipboard history.** On Windows each credential value and each kept clipboard item's text and files are encrypted with DPAPI for the current user, with Pane-specific entropy. The files move to format version 2, a version-1 file is converted at start in one atomic write, a failed conversion is retried at the next start, and a value that cannot be decrypted is explained and kept, never dropped. `credentials.get`/`set` are unchanged, and Clear cache, uninstall and retained-data counts work without decrypting anything. macOS and Linux keep today's user-only file; the documents state the protection per system.
- **#131 — a tray icon that survives Explorer.** The Windows tray adapter re-adds its icon when Windows broadcasts `TaskbarCreated`, only while the preference is to show it, with a stable GUID identity (name-based UUID from the program's canonical path, falling back to the numeric id) and a light or dark variant that follows the taskbar's theme (`SystemUsesLightTheme`, swapped in place on a theme change, loaded at the small-icon size for the display's DPI). The macOS menu-bar item shows Pane's mark as a template image and carries an autosave name. Linux is unchanged.
- **#132 — announcements of the selected row.** Keyboard focus stays in the query field; no row or computed answer claims focus. A hidden live region announces "`<title>`, `<i>` of `<n>`" on selection moves, "No results" for an empty list, a command's name and count when it opens, and toasts/outcomes before the selection. Rows carry their position and set size. The same behaviour covers root search, command lists, the actions panel, the footer menu, Clipboard History and Search Files.
- **#133 — a local crash record.** Every message Pane writes to standard error goes through one diagnostic path that also writes a size-capped (2 MiB, 5 rotations), rate-limited (10 lines a minute per site) and redacted (home path, user and computer names) log. A panic is written there before the process ends. A start marker removed on a clean quit lets the next start show one row, "Pane quit unexpectedly last time", whose action opens the logs folder; the About page shows the same notice and Copy diagnostics names the log. Nothing is sent anywhere.

  ```rust
      let identity = PackageIdentity::default_extension(&extension.id);
      let state = self.lock();

          && !state.retained.iter().any(|r| r.identity == identity)
  }
  ```

The cache** (`extensions/acquired/<id>/<version>-<integrity's first 16 hex digits>.tgz`, `.part` writes, abandoned after a day); **4. The install** ("unpacked with the same checks an npm package's tarball gets … installed exactly as a package from a folder is — into a managed copy, with the default extension's identity. … A default extension the user uninstalled, whose data Pane keeps, is not acquired again"). "What the user sees": status line "Acquiring the Calculator: 34% of 116 KiB", "Set up Pane's default extensions", root-search row **Set up Calculator** that retries. "The artifact source" section: `PANE_ARTIFACTS` loopback rule; "A development build with no `PANE_ARTIFACTS` acquires nothing". Limits: artifact source not deployed; **no default-extension updates** (uninstalling and restarting acquires the new version).
- **Packages do not ship defaults**: `xtask/src/package.rs` doc (lines 17-27) — the package holds "none of the default extensions' payloads (internet-first)"; `scripts/install-{linux.sh,macos.sh,windows.ps1}` headers: "The package holds none of Pane's default extensions: Pane downloads them itself at first setup".
- **Assembly**: `xtask/src/package.rs` as in §1 (`DEFAULTS`, `assemble_payloads`, `write_index`, `payload_files` at line ~382 which rewrites helper targets); xtask tests at lines 978-1070 (`the_default_extensions_are_no_samples`, `a_component_commands_share_is_packed_once` — Quicklinks' four commands pack the component once, `the_default_extensions_ship_the_images_their_icons_name` line 1067 iterating `DEFAULTS`).
- **Serving for smokes**: `scripts/artifact_server.py` serves `target/dist/artifacts` on 127.0.0.1 (usage `docs/installer.md` "Trying a first setup by hand"); measure scripts link the payloads without the `application` entry (`scripts/measure-linux.sh:470-484`).

## 9. Platform declarations and unavailable commands

- **Platform model**: `crates/pane-target/src/lib.rs` — `enum Platform { Windows, Macos, Linux }`, `Platform::ALL` (line 24), `Platform::current()` (line 29, `cfg!(target_os=…)`), `id()` `windows|macos|linux` (line 40), `from_id` (line 47); `Target { os, arch }` for helpers.
- **The refusal/explanation function — `crates/pane-core/src/platform.rs::unavailable(supported: Option<&[Platform]>, subject: &str)`** (lines 33-49): `Some(if supported.is_empty() { format!("Not available on {here}: {subject} supports no operating system") } else { format!("Not available on {here}: {subject} supports only {}", names(supported)) })`; `None` when it can run.
- **Install-time**: `Manifest::read_text` (packages.rs:704-707) returns `PackageError::UnsupportedPlatform(reason)` for a package not listing this system; npm/Git/dependency installs likewise (`dependencies.rs:828`, `operations.rs:247-248`) — note this means a Windows-only *default extension* payload would fail acquisition on macOS/Linux with "Could not set up the {title}: Not available on …", leaving the retry row — the reason ADR 0040 proposes the Windows-only default *set*.
- **Installed-but-elsewhere**: `Manifest::read_installed` (packages.rs:748) skips the platform check so "an installed copy of one lists its commands as unavailable".
- **Listed unavailable commands — `InstalledPackage::listed_commands()` (packages.rs:1959-1988)**: for each command, `unavailable = package.or_else(command-level platform::unavailable(..., "this command"))`, producing `ListedCommand { registration, unavailable, enabled, mode }` (line 1996); `available_commands()` (line 1924) filters enabled; `launchable_commands()` (line 1912) removes providers.
- **Root rows — `crates/pane-core/src/launcher.rs` (lines 3480-3527)**: for each `launchable_commands()` entry, `let unavailable = paused.clone().or(unavailable.map(Unavailable::OnThisSystem)); … Row { id, title, subtitle, unavailable }` and `Entry::Unavailable(reason)` — activating shows the reason as `Status::Error` and never opens.
- **`pub enum Unavailable` (launcher.rs:331-338)**: `OnThisSystem(String)` / `Paused(String)`, with `reason()` (line 399).
- **Item/action level — `CommandList::of` (launcher.rs:364-395)**: `let unavailable = platform::unavailable(item.platforms.as_deref(), "this action");` → `Entry::Unavailable(reason)` + `Row { …, unavailable: unavailable.map(Unavailable::OnThisSystem) }`.
- Full reference: `docs/platform-availability.md` (three declarations; "an omitted list means every system Pane runs on and an empty list (`[]`) means none"; Clipboard History is "the first package to use this").

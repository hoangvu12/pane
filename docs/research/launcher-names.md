# Launcher naming shortlist

Screened 2026-09-27 using exact-name web searches and first-party project/product pages where matches appeared. This is a preliminary collision screen, not proof of trademark, domain, package-name, or social-handle availability. No name has been selected by the user.

## Recommendation

**Keyroam** is my preferred fresh working name: keyboard-driven work that follows you between desktop operating systems. It is readable, pronounceable, and leaves room for more than application launching. Proposed description: “A small launcher you can make your own.” Proposed CLI spelling: `keyroam`.

The exact-name search did not surface an obvious established launcher. However, `keyroam.com` appeared in a domain reseller's listings, so do not assume that domain is freely registrable or required for the project. The search is not an exhaustive identity check. [Observed reseller listing](https://brandsly.com/name/roamcall-com)

| Candidate | Reason to consider | Concern |
|---|---|---|
| Keyroam | Keyboard + portability; clear product association | Longer than Pi; the .com appears in resale listings |
| Tesskey | Tessellation + keyboard; suggests small pieces composing a whole | Invented spelling needs a pronunciation/spelling test; preliminary searches did not reveal an obvious software product, which does not establish availability |
| Kyoko | Existing workspace name; distinctive personality | Already used by an open-source AI developer tool and its CLI, creating discoverability and command-name concerns |

Kyoko's collision is concrete: [kayba-ai/Kyoko](https://github.com/kayba-ai/Kyoko) distributes a local agent debugging tool using the `kyoko` command. Keeping it as an internal codename is possible; it is weaker as the public name for another developer tool.

## Names screened out

- **Kest:** existing API-testing CLI and other developer projects. [Kest](https://www.kest.dev/)
- **Keylet:** an authenticator app and a Python signing CLI. [Authenticator listing](https://play.google.com/store/apps/details?id=nl.studiofifteen.keylet), [Python package](https://pypi.org/project/keylet/)
- **Keyori:** existing real-estate referral software. [Keyori](https://keyori.io/)
- **Sprig:** crowded software name, including a keyboard-invoked macOS scratchpad. [Sprig Scratchpad](https://apps.apple.com/us/app/sprig-scratchpad/id6764240383?mt=12)
- **Tesslet:** existing native-widget product with a particularly close modular-app association. [Tesslet](https://tesslet.com/)
- **Kepli:** existing assistant app. [Kepli app listing](https://apps.apple.com/th/app/kepli/id6784746718)
- **Kernlet:** existing container-runtime project and OS terminology. [Container runtime](https://github.com/kodlabs-in/kernlet), [Managarm terminology](https://docs.managarm.org/handbook/impl-notes/drivers/irqs.html)

## Naming criteria

Prefer a name that is easy to say, type, search, and use as a command. Avoid implying a connection to Tinycast, Raycast, or Pi. Avoid making “AI” or a particular OS part of the name while those are optional capabilities. Pick the audience and product promise before making a public naming commitment; verify exact distribution namespaces and relevant branding rights before publication.
